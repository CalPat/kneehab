# kneehab v13.14 — park all box work; reframe the optional reactive entry as no-box

**Date:** 2026-06-24
**Type:** Minor (decision/reframe — the box ladder was already optional/dormant; this removes it from the active menu)

## Driver

Follow-on from v13.13. Discussion concluded that, with **rucking already in the plan**, box/drop jumps don't earn their knee risk for this user. Key reasoning:

- **Rucking and jumping load different axes.** Rucking adds strain *magnitude* (BW + pack) but is *low rate* (~1.1–1.5× BW, ~600–800 ms ground contact) — essentially heavy slow walking. Jumps are the *high-rate / impact* axis. They're complementary, not substitutes.
- **But the bone bases are already covered:** rope (rate) + ruck + heavy strength (magnitude) fill three of the four magnitude×rate cells. The empty cell (high-magnitude + high-rate, i.e. femoral-neck impact) is a small incremental gain — and bone's osteogenic response *saturates* at moderate impact (~3× BW hops), so the remainder is cheaply captured by low hops, not depth jumps.
- **The only thing box/drop jumps uniquely add is maximal reactive deceleration / landing capacity** — a ski/MTB *performance* quality, not a longevity one.
- For a **PFPS history** at the healthy + pain-free stage, that sport-transfer gain isn't worth the highest-knee-load, fatigue-valgus move in the catalogue.

**Decision:** skip ALL box work — both box jump-*up* (concentric-only, low value) and box drop/depth jumps (the "jump down" — high value but high risk).

## What changed

**Strength Plyo Primer (`sS_plyo`):**
- The optional progression entry retitled **"Optional — reactive entry (only if chasing ski/MTB landing)"**, rx → **"pogo hops → stuck-landing low broad jumps · no box."**
- Box jump-up and box drop/depth jumps explicitly **parked** (removed from the active ladder). Rationale baked in: bone covered by rope+ruck+strength; jumps only add reactive decel for sport.
- **No-box reactive entry** documented for if it's ever wanted: pogo hops → low broad jumps with a **stuck (held) landing** on flat ground to prove clean knee tracking; box/depth drops are the *last* step, gated behind bulletproof stuck landings (zero valgus, no effusion).
- Decision-tree "knees feel good" line updated to "(+ optional reactive work only if building ski/MTB landing — no box)."

**Also updated:** S-block `note` (v13.14 line prepended) and reference-hub Plyo card — both now state box work is parked and describe the no-box reactive entry.
