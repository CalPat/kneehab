# kneehab v13.12 — add Jump Rope loading option to the Collagen Block

**Date:** 2026-06-23
**Type:** Minor (one new loading option added to the `N` block — additive, reversible)

## Driver

Carried over from the prior session's open question. User trains Strength **fasted in the morning** (16:8 IF), so collagen — which is protein + calories and breaks the fast — can't be dosed in the AM training window. The afternoon **Collagen Block** is the natural home for tendon-targeted loading. The block's loading menu had no impact/plyo option that matches the underlying evidence.

**Key realization:** the loading stimulus in Shaw 2017 (gelatin + vitamin C → doubled P1NP collagen-synthesis signal) **was rope-skipping.** So "afternoon collagen → jump rope" isn't a proxy for the Baar protocol — it *is* the literal protocol. The afternoon timing also resolves the fasting conflict cleanly and fits Baar's "take collagen separate from a complete-protein meal" guidance.

## What changed

Added **Option 2: Jump Rope (Baar protocol)** to the Collagen Block (`N`) loading menu. The existing options renumbered down by one.

**New Collagen Block loading menu:**

| # | Option | Target |
|---|--------|--------|
| Default | Easy Movement — Walk or Bike | cartilage (cyclic compression) |
| **2 (NEW)** | **Jump Rope (Baar protocol)** | **tendon (patellar/quad, Achilles, plantar fascia)** |
| 3 | Isometric Circuit | tendons (no equipment) |
| 4 | Yoga Holds | fascia & joint capsules |
| 5 | Loaded Walk / Ruck | general CT |

**Jump Rope prescription (baked into the card):**
- **6–10 min, hard cap.** Synthesis signal saturates fast — past ~10 min no extra tendon benefit, only impact cost.
- **~45–60 min after the collagen dose** (CLAUDE.md timing already correct — circulating AAs peak during loading).
- **Primary loading:** patellar & quad tendon, Achilles, plantar fascia under cyclic strain.
- **Compensations to avoid:** don't chase volume (more ≠ more synthesis); soft/quiet forefoot landings, knees soft; stop on sharp pain.
- **Knees-permitting** — it's the Phase-1 lowest-amplitude plyo, user months pain-free; watch for effusion after.
- **Regression:** fewer minutes / no-rope pogo hops on soft surface. **Progression:** stays Phase 1 here; the Strength block's plyo phasing governs higher amplitude.
- Tendon needs ~6 hr between loading bouts to re-sensitize → naturally separated from morning strength work; they don't compete.

## Two-stream rationale preserved

- **Tendon adaptation** (relevant to PFPS history): now served by jump rope at the synthesis peak — the high-value target previously aimed at low-value walks.
- **Cartilage/joint comfort:** still served by daily collagen consistency + normal walking/cycling (the "easy movement" default) — that stream doesn't need the window.

## What did NOT change

- No existing option removed or re-prescribed — pure addition + renumber. Strength / Cardio / Rest / Warm-Up / Daily Habits untouched.
- Collagen dosing protocol (15g hydrolyzed Type I + 200mg vit C + 5g creatine, 2+ hrs post-protein) unchanged.
