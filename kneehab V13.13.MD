# kneehab v13.13 — jump rope becomes the Collagen-Block default; KB Swing is the sole morning Plyo Primer

**Date:** 2026-06-24
**Type:** Minor (relocation/rebalance — no new exercise introduced)

## Driver

Follow-on from v13.12. Adding jump rope to the Collagen Block left it living in **two** places — the morning Strength Plyo Primer (osteogenic/impact, fasted) and the afternoon Collagen Block (tendon synthesis, post-dose). User spotted the redundancy and proposed letting each session do one job. Chosen path: **Plan A** — jump rope as the near-daily Collagen-Block *default* (rotate occasionally), KB Swing as the sole morning primer.

## The logic

Jump rope's adaptation is set by **when** you do it relative to the collagen dose:
- **Morning, fasted:** vertical impact → osteogenic / bone (strain-rate stimulus).
- **Afternoon, post-collagen:** tendon collagen synthesis (Baar window) — *and* the same vertical impact, so it covers bone too.

Moving rope to the afternoon makes it do **double duty** (tendon + bone) in the optimal window, and because the Collagen Block runs ~daily, bone now gets **near-daily** strain-rate exposure instead of the old 3×/week morning rope — a net upgrade for the osteogenic goal, not a loss.

That frees the morning: **KB Swing alone is a legitimate primer** (hip-power CNS prime + posterior-chain activation before lifting; near-zero knee load — actually *more* knee-sparing than rope, so it survives a grumbly-knee day). Knee impact drops from two rope sessions/day to one.
