# kneehab v12.02 — Drop Scap Push-Up, Fold Scap Protraction into Down Dog

**Date:** 2026-05-21
**Type:** Minor (exercise removal + cue addition, no structural program change)
**Predecessor:** v12.01 (standing protocol added to Daily Habits)

## Driver

Observation: Down Dog already loads scap protraction (serratus anterior) in the same fiber pattern as Scap Push-Up — same protraction action, ~45° inverted instead of horizontal. At v12.01's reduced dose (1 prep set), Scap Push-Up was redundant if Down Dog is performed actively.

## Changes

### Cut · Scap Push-Up (Day B upper body)
Was 1 prep set in v12.01, demoted from 2-set training in v12.0. Now removed entirely from both the BLOCKS object (Day B Today rendering) and the schedule pane upper body card.

### New cue · "Press the floor, scaps wide" (Day A + Day B mobility)
Added to the Down Dog phase of the Cat-Cow → Down Dog → Up Dog flow. Active protraction for 3–5 breaths at the top of each Down Dog, deliberate floor-press, scapulae wide. Same serratus anterior recruitment pattern as Scap Push-Up.

Updated in three places:
- `src-mob` reference card (Exercises hub)
- Day A `sA_mob` BLOCKS detail (Today tab)
- Day B `sB_mob` BLOCKS detail (Today tab)

## What Did Not Change

- Cat-Cow stays primarily a spinal articulation drill — not a scap drill
- Up Dog stays a scap depression / retraction position
- Push-Up with Tempo (3×8 with 3s eccentric + 1s pause) continues to train scap stabilization under real horizontal-plane load. Scap Push-Up was only ever a prep set, never the training stimulus.
- Day A, Day R, Activity Day, Collagen Block, Daily Habits — all unchanged
- v12.0 KB additions and rotations stand; v12.01 standing protocol stands

## Tradeoff Acknowledged

Scap Push-Up loads protraction closer to actual push-up geometry (horizontal plane). Down Dog loads it at ~45° inverted. At 1 prep set the specificity loss is marginal — Push-Up itself provides the horizontal-plane scap loading during its 3 working sets.

## Net Time

Day B: ~38 → ~37.5 min. Trivial.
