# kneehab v13.11 — recluster Daily Warm-Up: floor → kneeling → standing

**Date:** 2026-06-18
**Type:** Minor (pure reorder of the `W` block — no items added/removed/changed in content)

## Driver

User: "Can Bird Dog and WLYT be moved earlier (floor based)?" Both sat at the end of the warm-up (positions 11–12) while standing items (Carry, Abduction, Mǎbù) and a floor item (Copenhagen) were interleaved — so the routine bounced floor ↔ standing repeatedly, forcing multiple get-up/get-down transitions.

## What changed

Reordered the 12 `W`-block items by **body position** to minimize transitions. Same 12 items, same content, same ~18 min — only sequence changed.

**New order:**

| # | Item | Position |
|---|---|---|
| 1 | 90/90 Hip Rotations | floor (seated) |
| 2 | Cat-Cow → Down Dog → Up Dog | floor (quadruped) |
| 3 | **Bird Dog** ← moved up | floor (quadruped) |
| 4 | **WLYT** ← moved up | floor (prone) |
| 5 | Core Hold Combo | floor (supine→prone) |
| 6 | Copenhagen Plank | floor (side-lying) |
| 7 | Hip Flexor (Tuck L-Sit / Hanging) | floor (seated) default |
| 8 | Half-Kneeling Rotation | kneeling |
| 9 | Kneeling Ankle Dorsiflexion | kneeling |
| 10 | Suitcase Carry | standing (loaded) |
| 11 | Standing Hip Abduction (banded) | standing (loaded) |
| 12 | Mǎbù (Horse Stance) | standing (loaded) |

**Result:** down once for the whole floor block (1–7), up to kneeling (8–9), then the standing loaded work last (10–12) when fully warm. Bird Dog now follows Cat-Cow in the same hands-and-knees position; WLYT (prone) follows it. The mobilize → activate → load progression is *improved* as a side effect — light floor mobility/activation first, heaviest standing work last.

- Bird Dog and WLYT detail blocks tagged "v13.11 — moved up into the floor block."
- Hip Flexor note adds: if using the Hanging Knee Raise variant (bar), do it with the standing block instead.
- Reference hub (`src-warmup`) cards reordered to match the Today-tab sequence.

## What did NOT change

- No item added, removed, or re-prescribed. Strength / Cardio / Rest / Daily Habits untouched.
- All v13.1 content stands (see below).
